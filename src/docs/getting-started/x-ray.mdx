This page is deprecated. It described how to send traces from the ADOT Collector with the AWS X-Ray exporter (awsxray). Send traces to the CloudWatch OTLP traces endpoint (`https://xray.<region>.amazonaws.com/v1/traces`) instead, using the `otlp_http` exporter with SigV4 authentication. The OTLP traces endpoint requires Transaction Search, and accepts W3C trace IDs, so you don't need the X-Ray ID generator.

## Use these resources instead

- [Sending OpenTelemetry data to CloudWatch OTLP endpoints](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-OTLPSimplesetup.html)
- [CloudWatch OTLP endpoints](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-OTLPEndpoint.html)
- [Transaction Search](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/CloudWatch-Transaction-Search.html)
