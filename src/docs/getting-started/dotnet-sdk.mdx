OpenTelemetry provides different language SDKs to instrument customer applications for collecting telemetry data.

Below are links to guides that go over how to use AWS Distro for OpenTelemetry (ADOT) .NET auto-instrumentation to send traces and metrics to AWS, including Amazon CloudWatch (directly to the CloudWatch OTLP endpoints or through the CloudWatch agent), and CloudWatch Application Signals.
