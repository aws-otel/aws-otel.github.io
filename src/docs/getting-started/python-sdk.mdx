The AWS Distro for OpenTelemetry (ADOT) Python refers to some components developed to complement the upstream [OpenTelemetry (OTel) Python SDK](https://github.com/open-telemetry/opentelemetry-python/tree/main/opentelemetry-sdk). Below are links to guides that go over how to use ADOT Python to send traces, metrics, and logs to AWS, including AWS X-Ray, Amazon CloudWatch (directly to the CloudWatch OTLP endpoints or through the CloudWatch agent), and CloudWatch Application Signals.
